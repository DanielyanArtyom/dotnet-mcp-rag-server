- **Azure v1 API работает** с ресурсом AI Foundry (`https://<name>.services.ai.azure.com/openai/v1/`, не только `*.openai.azure.com`), deployment `text-embedding-3-small`, ключ — закрывает открытый вопрос research'а Stage 3 про покрытие `/embeddings` GA-подмножеством v1.

С fake такое невозможно — fake находит только байт-в-байт идентичный текст чанка целиком.

- **Удаление каскадит векторы:** после `DELETE` поиск по документу → 200 с пустым массивом.
