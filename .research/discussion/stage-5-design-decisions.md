## Вводная

Перед этапом Claude перечитал README, DECISIONS и весь `.research/`. Кросс-этапные заметки о MCP (`../mcp-csharp-sdk.md`, `../mcp-client-auth.md`) были от 2026-09-09 и частично устарели, поэтому сначала сделан research-проход из четырёх тем (SDK, авторизация и клиенты, дизайн RAG-тулов, тестирование), каждая — фоновым агентом по первоисточникам.

## Что research изменил в картине

1. **Спецификация MCP 2026-07-28 сделала протокол stateless** (без `initialize`, без `Mcp-Session-Id`); SDK 2.0+ по умолчанию stateless, 2.2.0 обслуживает и клиентов 2025-11-25.
2. **Stateless — требование корректности изоляции, а не выбор масштабирования.** Только в stateless тул выполняется в DI-scope HTTP-запроса и видит `ICurrentTenant` из `TenantResolutionMiddleware`; в stateful тенант пустой и поиск молча возвращает ноль строк. Подтверждено по исходникам SDK v2.2.0 и спайком агента. Следствие: тест изоляции через MCP обязан иметь позитивный контроль (свои чанки находятся).
3. **OAuth-метаданные (PRM) без своего authorization server невалидны** (`authorization_servers` должен быть непустым) — значит, никакого `AddMcp()`-scheme и `/.well-known/oauth-protected-resource`.
4. **Claude Code `headersHelper`** — штатный механизм для короткоживущих токенов (перезапуск при 401/403 и повтор вызова).
5. **Проверку `Origin` спецификация требует, SDK её не делает** — пишем сами.
6. **Вендоры в большинстве выставляют search + fetch** и отдают синтез модели клиента; server-side «answer»-тул — редкость, и Anthropic предупреждает о путанице пересекающихся тулов.
7. Отказ от Claude Desktop в силе (#644/#685 открыты, `static_headers` — бета для организаций).

## Решения по порядку

|---|--------|---------|---------|--------------------|
| 1 | Какие тулы | **Только поиск:** `search_filings` + `list_filings`; `ask` в MCP не выставляем (пользователь: «по простому через А») | Клиент — сам сильная модель, вложенный gpt-4o лишний; так делает большинство вендоров; и это даёт честный эксперимент M1 без нового API-кода | M1 покажет, что Claude по сырым чанкам заметно хуже `/api/ask` (87 %) — тогда `ask_filings` отдельным шагом |
